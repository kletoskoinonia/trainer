# Biblical Languages Trainer

Biblical Languages Trainer and Interlinear Bible with Lessons, Reading Plan, Church History and Notes — developed by Kletos Koinonia.

Open it: https://kletoskoinonia.github.io/trainer/ (on iPhone/iPad: Safari › Share › Add to Home Screen).
